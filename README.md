SPECRITM — это десктопное приложение для повышения личной продуктивности, которое объединяет компьютерное зрение, машинное обучение и анализ поведения пользователя. Суть проекта заключается в том, что система в реальном времени через веб-камеру отслеживает физиологическое и эмоциональное состояние человека, анализирует его и предлагает оптимальные действия в текущий момент времени. Это позволяет пользователю работать продуктивнее, не перегружаясь и с учётом своих биоритмов. Приложение подходит для фрилансеров, удалённых сотрудников, студентов, школьников, исследователей, а также для практиков осознанности и биохакинга, которым важно контролировать энергию и внимание в течение дня.

Технически система состоит из двух основных потоков: поток обработки видео `CamThread` и поток вычисления рекомендаций `Engine`. Видео поток использует **Mediapipe** для детекции лица и глаз и вычисления метрик, таких как **EAR (Eye Aspect Ratio)** — коэффициент, показывающий степень открытия глаз. EAR вычисляется на основе расстояний между ключевыми точками вокруг глаз и позволяет точно определять моргание, длительность закрытия глаз и, соответственно, уровень сонливости пользователя. Также Mediapipe используется для оценки угла наклона головы, что дополнительно влияет на вычисление энергетического состояния.

Для распознавания эмоций применяется **OpenVINO**, который позволяет запускать предобученные модели эмоций (например, `emotions-recognition-retail-0003`) с высокой скоростью инференса на CPU. Модель оценивает вероятность различных эмоциональных состояний — нейтральное, счастье, грусть, гнев, удивление — и передаёт вероятности в движок расчёта рекомендаций. Внутри `Engine` эти вероятности преобразуются в фактор эмоционального состояния E с использованием сигмоидной функции. А также скоро добавиться учет и корректировка на основе аудиоподсказок, если они есть.

Алгоритм рекомендаций SPEC учитывает четыре компонента: **S (Energy)**, **E (Emotion)**, **P (Time)** и **C (Capacity)**. S вычисляется на основе EAR, частоты моргания и угла головы: глаза имеют вес 50%, моргание — 30%, поза головы — 20%. E рассчитывается по вероятностям эмоций с учётом категории задачи (ментальная, физическая, креативная) и корректировкой аудио. P учитывает биоритмы пользователя, используя оптимальное время выполнения задач для каждой категории, реализованное через Gaussian-функцию с пиком и вторым окном. C отражает соответствие сложности задачи текущему уровню энергии и вычисляется как произведение**, **(1 - difficulty) * S**. Итоговый score задачи формируется как взвешенная сумма этих факторов с настраиваемыми коэффициентами: **Productivity = S*w_S + E*w_E + P*w_P + C*w_C**. Если задача запланирована на текущее время, score дополнительно увеличивается, что придаёт приоритет текущим действиям.

Все данные о сессиях, активности и факторах хранятся локально в **SQLite**, что обеспечивает приватность. История рекомендаций и метрик позволяет системе учитывать тренды и корректировать будущие рекомендации. Пользователь может давать обратную связь после каждой сессии, и на её основе алгоритм корректирует свои веса, то есть система **дообучается под конкретного пользователя**.

Интерфейс реализован на **PyQt6**, отображает видео с камеры, графики продуктивности, тренды, таблицы с активностями и рекомендации. Обработка видео и вычисления происходят в реальном времени, задержка расчёта рекомендации обычно менее 50 мс, что делает работу системы плавной и интерактивной.

Технологический стек включает Python 3.8+, PyQt6 для UI, OpenCV для работы с видео, Mediapipe для детекции лица и вычисления EAR, OpenVINO для инференса модели эмоций, NumPy для математических вычислений, SQLite для хранения данных и стандартные библиотеки threading/QThread для параллельной обработки видео и вычислений.

Таким образом, PugRitm сочетает **компьютерное зрение**, **анализ эмоций**, **биоритмы пользователя**, **учёт сложности задач** и **обратную связь** для генерации максимально персонализированных рекомендаций, позволяя пользователю повышать продуктивность без перегрузки, с учётом физиологических и эмоциональных состояний.
